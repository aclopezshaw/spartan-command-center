# Phase III artwork production prompts

**Status:** Proposed  
**Method:** Built-in image generation and localized image editing; one call per asset or revision. Scenes use `transparent_background: false`; patch concepts use `true`.  
**Date:** 2026-11-10

These are review drafts. See the [asset inventory and review boundaries](PHASE_III_ART_REVIEW.md) and [visual gallery](phase-iii-art-gallery.html). Earlier generated assets are preserved; new scene files use Phase III-specific filenames. All generation and localized uniform editing used the built-in image tool; no CLI image model or external pixel editing was used.

## Reference roles

- Morning anchor: Phase II morning berth for existing architecture/materials; active Assembly Hall for academy styling; approved Athena v2 patch for the wall plaque.
- Remaining ordinary plates: generated morning anchor for room continuity; approved Athena v2 patch for identity.
- Eight event scenes: generated morning anchor for architecture and wall insignia; canonical Michael, Paige, Ellie and Zoe dossier PNGs (in that order) for faces and uniforms. Exactly five reference paths per call. Event prompts retain the existing SCP/Epsilon sleeve identity and do not approve a new Athena wear position.
