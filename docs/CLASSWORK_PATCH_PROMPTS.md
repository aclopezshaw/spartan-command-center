# Classwork achievement patch prompts

**Status:** Implemented  
**Method:** Built-in image generation, one call per tier, `transparent_background: true`.  
**Date:** 2026-11-10

Each image was generated from its corresponding approved unnumbered master. Original outputs and masters are preserved; selected PNGs are copied without external pixel editing. All twelve are 1254 × 1254 RGBA PNGs. See [Classwork Achievements](CLASSWORK_ACHIEVEMENTS.md) for earning rules.
